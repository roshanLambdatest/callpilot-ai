# DEMO DATA — Integrations Guide

> Fictional demo content for evaluation only.

Nimbus can ingest knowledge from local PDF, DOCX, Markdown, and TXT files in the demo. The enterprise product concept includes Jira and Confluence connectors. Slack can be used for post-call summaries and alerts, while CRM integrations can attach meeting notes to an opportunity.

For real-time answering, the Call Copilot retrieves only the most relevant chunks from the indexed knowledge base and sends those excerpts with the customer's question to the selected language model. This reduces context size and helps keep answers grounded.

The demo does not automatically join Google Meet, Microsoft Teams, or Zoom as a bot. Its Live Demo mode can use browser microphone audio, or browser shared-tab audio when the browser exposes that audio track and the user explicitly grants permission.
