# DEMO DATA — Nimbus Security and Enterprise FAQ

> Fictional demo content. Do not treat these statements as real vendor claims.

## Data handling

Customer knowledge files are indexed for retrieval. In the standard hosted configuration, the application stores uploaded files and extracted chunks in the customer's tenant. Administrators can delete indexed documents from the knowledge base.

## Grounded answers

The Call Copilot is designed to answer from retrieved knowledge snippets. If the retrieved evidence is weak, it should state that the answer could not be verified instead of inventing a capability.

## Access control

The production roadmap supports SSO, role-based access control, and workspace-level knowledge segregation. The demo build does not include production authentication and must not be exposed directly to the public internet.

## Compliance

No compliance certification should be claimed based on this demo document. Compliance questions must be verified against a current approved security or legal source before being answered to a customer.
